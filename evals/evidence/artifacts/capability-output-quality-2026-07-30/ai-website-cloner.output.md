## 定价页重建工作包（待采集后实施）

已采用“仅借鉴布局节奏与组件关系”的范围：不复制商标、原文案、图片、客户 Logo、专属插图或任何来源识别元素。目标站点归属及分析授权仅作为本任务前提，未作独立核验。

### 当前阻断

尚未提供目标定价页的 URL、截图、录屏、HTML/CSS 或目标项目资料，因此不能确认其实际区块顺序、比例、响应式行为和交互状态，不能声称完成该页复刻。

最小解除阻断输入：

1. 桌面端全页截图（建议 1440px 宽）与移动端全页截图（建议 390px 宽）。
2. 定价周期切换、套餐推荐态、悬浮提示、展开项等状态截图或录屏。
3. 目标项目目录或技术栈、路由位置、现有设计系统与验证命令。
4. 自有品牌的 Logo、色板、字体许可范围、产品命名、套餐及 CTA 文案。

### 页面骨架候选


### 设计 Token（待从证据校准）

| 类别 | 初始语义 Token | 用途 |
|---|---|---|
| 页面背景 | `--surface-page` | 整体留白与分区底色 |
| 卡片背景 | `--surface-card` | 套餐卡与对比区容器 |
| 主文字 | `--text-primary` | 标题、价格、重点内容 |
| 次文字 | `--text-secondary` | 功能说明、辅助信息 |
| 品牌强调 | `--brand-primary` | 主 CTA、推荐套餐强调 |
| 边框 | `--border-subtle` | 卡片与表格分隔 |
| 圆角 | `--radius-card` | 套餐卡、按钮、标签 |
| 阴影 | `--shadow-elevated` | 推荐卡或浮层 |
| 间距 | `--space-1` 至 `--space-10` | 区块、卡片、文本节奏 |
| 字级 | `--type-display` 至 `--type-caption` | 标题、价格、正文层级 |

### 品牌替换表

| 原页面元素类型 | 重建处理 |
|---|---|
| 商标、产品名称 | 替换为自有品牌资产与命名 |
| 所有可识别文案 | 按自有产品价值与套餐规则重写 |
| 产品截图、插图、人物图 | 使用自有、已授权或新制作素材 |

| 品牌色、字体 | 使用自有设计系统；仅保留经证据确认的层级与节奏关系 |
